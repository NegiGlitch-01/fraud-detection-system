# 💳 Fraud Detection System

🚀 A Machine Learning web application that detects fraudulent financial transactions using a Decision Tree model.

---

## ✨ Features

- 🔍 Real-time fraud detection  
- 🌐 Interactive Streamlit web interface  
- ⚡ Fast and accurate predictions  
- 🎯 Simple and user-friendly UI  

---

## 🛠 Tech Stack

- 🐍 Python  
- 🎈 Streamlit  
- 🤖 Scikit-learn  
- 🔢 NumPy  
- 📊 Pandas  

---
